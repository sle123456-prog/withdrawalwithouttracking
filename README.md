# 一次性中转钱包（Chrome 插件）

中文 | [English](README.en.md)

从交易所提币时，为每一次提币生成一个全新的一次性 EVM 地址；资金到账后自动转入你的目标地址 B（同链）。

## 安装

1. 打开 `chrome://extensions`，右上角开启“开发者模式”
2. 点“加载已解压的扩展程序”，选择本仓库的 `extension/` 目录（或解压 `dist/` 里的 zip 后得到的 `extension` 文件夹）
3. 点击工具栏里的插件图标，打开应用页面

## 使用

1. 选择链、要接收的币种（原生币 / USDT / USDC / 任意代币合约地址），填入目标地址 B
2. 点“生成一次性地址”，复制地址或扫二维码，在交易所提币到该地址
3. 到账后程序自动把全部资金转到 B；**转出完成前请保持页面打开**
4. 点“重置 / 新地址”或重新打开程序，即可输入新的 B 并得到一个新的一次性地址

支持的链：Ethereum、BNB Smart Chain、Polygon、Arbitrum、Optimism、Base、Avalanche、Linea、zkSync Era、Scroll、Mantle、Gnosis。可在“高级”里填自己的 RPC。

## Gas 费说明

- **提原生币（ETH/BNB/POL…）**：手续费直接从到账金额里扣，不需要 Gas 钱包。
- **提代币（USDT/USDC…）**：需要先在页面下方配置 **Gas 钱包**（导入私钥或生成新钱包，保存一次后续一直可用）。
  代币到账后，Gas 钱包自动给中转地址垫付所需 gas（按预估多给 30%），代币转给 B 后，剩余 gas 自动退回 Gas 钱包。
  同一个 Gas 钱包通用于所有 EVM 链，但要在你使用的那条链上有少量原生币；余额不足时页面会提示充值多少，充值后自动继续。

### 为什么不支持 Bitget Wallet 免 Gas 转账

曾考虑接入 Bitget Wallet 的免 Gas 转账（手续费从 USDT/USDC 中扣除，无需 Gas 钱包），最终放弃：
Bitget Wallet 的文档没有写明该方式支持的最低金额，无法事先告诉用户一笔转账能否成功走免 Gas。
为防止误导用户，本程序不提供该选项，代币转出统一使用 Gas 钱包代付。

## 安全与限制

- 私钥在本机随机生成，只保存在浏览器的插件存储里（未加密），不会上传。
- 重置后的旧地址保留在“历史地址”里，后续误打入的资金可点“恢复”继续转出；也可在会话页导出私钥。
- 链上转账是公开的：“交易所 → 中转地址 → B”这条路径任何人都能在区块浏览器上查到。
  本工具只是让交易所的提币记录里不直接出现 B，并不能提供混币级别的匿名性。
- Gas 钱包的私钥同样未加密保存在本机，请只放少量 gas 费。
- Gas 钱包会在链上与每一个中转地址产生转账记录，因此通过它可以把你的各个中转地址关联起来。
- 第一次使用请先小额测试。
