# 一次性中转钱包（Chrome 插件）

中文 | [English](README.en.md)

从交易所提币时，为每一次提币生成一个全新的一次性 EVM 地址；资金到账后自动转入你的目标地址 B（同链）。

界面支持中文和英文：默认跟随浏览器语言，可用页面右上角的按钮切换。

## 2.0beta：Tornado Cash 模式

在生成地址前打开 **Tornado Cash 模式**。选链、选币种、填写 B、复制收款地址的操作不变。程序会额外生成第二个一次性钱包，按下面的路径处理本轮资金：

`交易所 → 第一钱包 → Tornado Cash 固定面额资金池 → 第二钱包 → B`

- 首次达到可存入金额时，冻结本轮金额并拆成资金池支持的面额；单轮最多 100 笔。无法凑足面额的尾款、预留但未花完的手续费，以及之后转入第一钱包的资金均留在第一钱包，并显示实际余额。
- 本轮每笔提款均需达到 12 个区块确认，并核对链上提款凭证和第二钱包实际余额；全部成功后，第二钱包才统一向 B 转出选定资产。到账金额扣除存款手续费、中继费用和最终转账手续费。
- 支持 Ethereum、BNB Smart Chain、Polygon、Arbitrum、Optimism、Avalanche、Gnosis 的已有原生币资金池，以及 Ethereum 的 DAI、USDC、USDT 固定面额资金池。其他链或代币在生成地址前提示不支持。ETH 最小面额为 0.1 ETH，另需手续费；USDC/USDT 面额为 100、1000。
- 自动从链上注册表发现中继，也可在高级设置填写兼容中继地址。无可用中继、手续费过高、RPC 无法同步、余额不足时暂停并重试，不直接绕过混币。首次同步链上历史记录可能需要较长时间。
- 页面展示存入、提取、第二钱包汇总和转 B 的进度。每笔凭证和签名交易先持久保存，再广播；重启按链上记录恢复。多个窗口中只有一个窗口可操作钱包。
- 用“导出完整备份”保存两把私钥和全部 Tornado 存款凭证。备份属于敏感私密数据；提款证明在本机生成，中继只收到证明和公开交易参数。更新时覆盖文件并刷新扩展，不要先卸载。

本功能直接使用白名单中的 Classic 合约，所给网站提供参考入口；不把私钥或存款凭证交给网页。资金池和中继可用性取决于实际网络情况。立即提取、金额组合和最终转账仍可能提供关联线索，不承诺无法追踪。

### 构建 2.0beta

本分支新增的零知识证明依赖和电路文件在构建时生成。首次从源码安装需 Node.js 20 或更新版本：

```sh
npm ci --ignore-scripts
npm run build
npm test
```

构建会下载固定版本的上游电路归档，校验 Git blob SHA，并生成本地证明器、静态 Worker 和电路文件。扩展运行时不下载或执行远程 JavaScript。构建后按下方步骤加载 `extension/`，或使用已构建的发行 ZIP。开发验证另可运行 `npm run test:browser`。

Tornado 上游来源：[界面和部署配置](https://github.com/tornadocash/tornado-classic-ui/tree/a83fae0772c8da084c0e76b3a756b456f5b9f5bb)、[核心合约](https://github.com/tornadocash/tornado-core)。

## 安装

1. 打开 `chrome://extensions`，右上角开启“开发者模式”
2. 点“加载已解压的扩展程序”，选择本仓库的 `extension/` 目录（或解压 `dist/` 里的 zip 后得到的 `extension` 文件夹）
3. 点击工具栏里的插件图标，打开应用页面

## 使用

1. 选择链、要接收的币种（原生币 / USDT / USDC / 任意代币合约地址），填入目标地址 B
2. 点“生成一次性地址”，复制地址或扫二维码，在交易所提币到该地址
3. 到账后程序自动把全部资金转到 B；**转出完成前请保持页面打开**
4. 点“重置 / 新地址”或重新打开程序，即可输入新的 B 并得到一个新的一次性地址

支持的链：Ethereum、BNB Smart Chain、Polygon、Arbitrum、Optimism、Base、Avalanche、Linea、zkSync Era、Scroll、Mantle、Gnosis。可在“高级”里填自己的 RPC。

## Gas 费说明

- **提原生币（ETH/BNB/POL…）**：手续费直接从到账金额里扣，不需要 Gas 钱包。
- **提代币（USDT/USDC…）**：需要先在页面下方配置 **Gas 钱包**（导入私钥或生成新钱包，保存一次后续一直可用）。
  代币到账后，Gas 钱包自动给中转地址垫付所需 gas（按预估多给 30%），代币转给 B 后，剩余 gas 自动退回 Gas 钱包。
  同一个 Gas 钱包通用于所有 EVM 链，但要在你使用的那条链上有少量原生币；余额不足时页面会提示充值多少，充值后自动继续。

### 为什么不支持 Bitget Wallet 免 Gas 转账

曾考虑接入 Bitget Wallet 的免 Gas 转账（手续费从 USDT/USDC 中扣除，无需 Gas 钱包），最终放弃：
Bitget Wallet 的文档没有写明该方式支持的最低金额，无法事先告诉用户一笔转账能否成功走免 Gas。
为防止误导用户，本程序不提供该选项，代币转出统一使用 Gas 钱包代付。

## 安全与限制

- 私钥在本机随机生成，只保存在浏览器的插件存储里（未加密），不会上传。
- 重置后的旧地址保留在“历史地址”里，后续误打入的资金可点“恢复”继续转出；也可在会话页导出私钥。
- 链上转账是公开的：“交易所 → 中转地址 → B”这条路径任何人都能在区块浏览器上查到。
  本工具只是让交易所的提币记录里不直接出现 B，并不能提供混币级别的匿名性。
- Gas 钱包的私钥同样未加密保存在本机，请只放少量 gas 费。
- Gas 钱包会在链上与每一个中转地址产生转账记录，因此通过它可以把你的各个中转地址关联起来。
- 第一次使用请先小额测试。
