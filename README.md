# 一次性中转钱包（Chrome 插件）

中文 | [English](README.en.md)

从交易所提币时，为每一次提币生成一个全新的一次性 EVM 地址；资金到账后自动转入你的目标地址 B（同链）。

界面支持中文和英文：默认跟随浏览器语言，可用页面右上角的按钮切换。

## 2.1.0-beta：Tornado Cash 模式

接收币种选择 **ETH 原生币**，且当前链支持 Tornado Cash 时，才显示 **Tornado Cash 模式** 开关。目前符合条件的链为 Ethereum、Arbitrum、Optimism；切换到其他币种或链会自动关闭并隐藏该开关。打开模式后，填写 B、复制收款地址的操作不变。程序会额外生成第二个一次性钱包，按下面的路径处理本轮资金：

`交易所 → 第一钱包 → Tornado Cash 固定面额资金池 → 第二钱包 → B`

- 首次达到可存入金额时，冻结本轮金额并拆成资金池支持的面额；单轮最多 100 笔。无法凑足面额的尾款、预留但未花完的手续费，以及之后转入第一钱包的资金会先留在第一钱包，并显示实际余额。本轮完成后继续监听：余额再次满足 0.1 ETH 本金及所需 Gas 时，自动开始下一轮；页面关闭时暂停，重新打开此会话后继续。历次完整凭证保存在备份的 `mixHistory` 中，也可导出私钥自行处理残余资金。
- 本轮每笔提款均需达到 12 个区块确认，并核对链上提款凭证和第二钱包实际余额；全部成功后，第二钱包才统一向 B 转出选定资产。到账金额扣除存款手续费、中继费用和最终转账手续费。
- 新建混币会话仅开放上述链的 ETH 固定面额资金池。ETH 最小面额为 0.1 ETH，另需手续费；其他币种或链可使用普通中转模式。
- 自动从链上注册表发现中继，也可在高级设置填写兼容中继地址。无可用中继、手续费过高、RPC 无法同步、余额不足时暂停并重试，不直接绕过混币。首次同步链上历史记录可能需要较长时间。
- 页面展示存入、提取、第二钱包汇总和转 B 的进度。每笔凭证和签名交易先持久保存，再广播；重启按链上记录恢复。多个窗口中只有一个窗口可操作钱包。
- 用“导出完整备份”保存两把私钥和全部 Tornado 存款凭证。备份属于敏感私密数据；提款证明在本机生成，中继只收到证明和公开交易参数。更新时覆盖文件并刷新扩展，不要先卸载。

### 费用预估

普通转账和 Tornado 的网络 Gas 分别显示为当前链原生币与 USD 参考金额。Tornado 另列中继服务费与预计总费用；未取得费率时注明获取条件，不把网络 Gas 冒充全部费用。

当前版本不会在入金前查询中继费率：只有启用 Tornado、到账金额达到本金和 Gas 要求并获得足够确认，准备存款时才会选择中继并报价。因此，入金前等待或点击“刷新预估”只能更新网络 Gas 和币价，不会让中继服务费自动出现。

入金前默认按一笔 0.1 ETH 存款估算，可选填 0.1 整倍数的预计混币本金查看多笔成本；这个输入只影响预估，不改变实际转账金额。开始处理后按本轮实际存款计划估算，费用保留余量，仍以执行时网络费和中继报价为准。Tornado Gas 成本极高，小额慎用，小白禁用。

Gas 价格来自所选 RPC。USD 使用 [CoinGecko](https://docs.coingecko.com/demo/reference/simple-price) 或 [DefiLlama](https://docs.llama.fi/list-your-project/how-to-request-token-pricing) 的原生币参考价格，仅查询币种标识，不向行情服务传递地址、私钥或存款凭证。价格服务故障时保留原生币估算，并标明缓存时间或 USD 无法换算；L2 数据费缺失时明确提示费用不完整。可手动刷新，页面也会定期更新。

本功能直接使用白名单中的 Classic 合约，所给网站提供参考入口；不把私钥或存款凭证交给网页。资金池和中继可用性取决于实际网络情况。立即提取、金额组合和最终转账仍可能提供关联线索，不承诺无法追踪。

### 构建 2.1.0-beta

本分支新增的零知识证明依赖和电路文件在构建时生成。首次从源码安装需 Node.js 20 或更新版本：

```sh
npm ci --ignore-scripts
npm run build
npm test
```

构建会下载固定版本的上游电路归档，校验 Git blob SHA，并生成本地证明器、静态 Worker 和电路文件。扩展运行时不下载或执行远程 JavaScript。构建后按下方步骤加载 `extension/`，或使用已构建的发行 ZIP。开发验证另可运行 `npm run test:browser`。

Tornado 上游来源：[界面和部署配置](https://github.com/tornadocash/tornado-classic-ui/tree/a83fae0772c8da084c0e76b3a756b456f5b9f5bb)、[核心合约](https://github.com/tornadocash/tornado-core)。

## 安装

安装本分支的 `2.1.0-beta` 时，请先按上方步骤构建，再加载 `extension/`。`dist/relay-wallet-extension-v1.3.0.zip` 为历史 v1.3.0 安装包。

1. 打开 `chrome://extensions`，右上角开启“开发者模式”
2. 点“加载已解压的扩展程序”，选择本仓库的 `extension/` 目录（或解压 `dist/` 里的 zip 后得到的 `extension` 文件夹）
3. 点击工具栏里的插件图标，打开应用页面

## 使用

首次使用先设置 Passkey 或密码；后续打开页面先解锁。

1. 选择链、要接收的币种（原生币 / USDT / USDC / 任意代币合约地址），填入目标地址 B
2. 点“生成一次性地址”，复制地址或扫二维码，在交易所提币到该地址
3. 普通模式到账后自动转到 B；Tornado 模式按上方说明经过两个钱包和资金池，尾款留在第一钱包。**转出完成前请保持页面打开**
4. 点“重置 / 新地址”或重新打开程序，即可输入新的 B 并得到一个新的一次性地址

支持的链：Ethereum、BNB Smart Chain、Polygon、Arbitrum、Optimism、Base、Avalanche、Linea、zkSync Era、Scroll、Mantle、Gnosis。可在“高级”里填自己的 RPC。

## Gas 费说明

- **提原生币（ETH/BNB/POL…）**：手续费直接从到账金额里扣，不需要 Gas 钱包。
- **提代币（USDT/USDC…）**：转出代币要用中转地址上的原生币付 gas。代币到账后：
  - 中转地址上的原生币够用：直接转出，不动用 Gas 钱包；剩余的 gas 留在一次性地址，不会转给 B。
  - 不够用且已绑定 **Gas 钱包**：Gas 钱包自动补足差额（按预估多给 30%），代币转给 B 后，剩余 gas 退回 Gas 钱包。
  - 不够用且没有绑定 Gas 钱包：页面提示所需金额，你可以手动向中转地址转入少量原生币，或当场绑定 Gas 钱包；到账或绑定后自动继续。手动转入时剩余的 gas 同样留在一次性地址。
- **留在一次性地址上的剩余 gas**：程序不会自动转走。需要取回时，在会话页（或先在“历史地址”里恢复该地址）导出私钥，导入任意钱包自行转出。
- **Gas 钱包是可选的**：在页面下方导入私钥或生成新钱包，保存一次后续一直可用。同一个 Gas 钱包通用于所有 EVM 链，但要在你使用的那条链上有少量原生币；余额不足时页面会提示充值多少，充值后自动继续。

普通模式的原生币按一笔转账估算；代币参考预估包含补 Gas 和代币转账，绑定 Gas 钱包时还包含退款交易。实际已有 Gas 时可能减少交易笔数。原生币及 USD 展示规则见上方“费用预估”。

### 为什么不支持 Bitget Wallet 免 Gas 转账

曾考虑接入 Bitget Wallet 的免 Gas 转账（手续费从 USDT/USDC 中扣除，无需 Gas 钱包），最终放弃：
Bitget Wallet 的文档没有写明该方式支持的最低金额，无法事先告诉用户一笔转账能否成功走免 Gas。
为防止误导用户，本程序不提供该选项，代币转出使用中转地址的原生币支付，可手动充值或由可选 Gas 钱包代付。

## 私钥加密

**新安装必须先设置私钥加密**，设置完成后才能使用其他功能。有两种解锁方式：

- **Passkey**：用通行密钥（指纹 / 面容 / PIN）解锁。需要该 Passkey 所在的设备或密码管理器支持 WebAuthn 的 PRF 扩展，不支持时页面会提示，此时请改用密码。
- **密码**：至少 8 位，任何环境都可用。
- 两种方式可以同时设置，任意一种都能解锁。**建议两种都设**：解锁方式全部丢失（删除了 Passkey、换了设备、忘记密码）后，已保存的私钥无法恢复。

加密之后：

- 当前会话、历史地址和 Gas 钱包（含私钥和地址）整体用 AES-256-GCM 加密后保存，不留明文。
- 每次打开或刷新页面都需要先解锁；上锁期间不会监听和转出，解锁后自动继续。
- “显示私钥”（当前会话和 Gas 钱包）以及 Tornado“导出完整备份”每次都需要再验证一次 Passkey 或密码。
- 新增另一种解锁方式也需先验证已有方式。加密开启后不能关闭。
- 加密保护的是存在磁盘上的数据。页面解锁期间私钥在内存中，无法防范已经能控制你浏览器的恶意软件。

**从 1.2.x 及更早版本或未加密的 beta 升级**：原有的明文数据会保留，可以继续使用，但页面会提示尚未加密，并且在开启加密之前无法显示私钥或导出完整备份。开启加密后明文会被删除。

Tornado 模式的两个钱包私钥、存款凭证、交易日志和历次 `mixHistory` 一并加密保存；历史余额也会显示第二钱包。导出的备份仍为明文，请妥善保管。

## 安全与限制

- 私钥在本机随机生成，只保存在浏览器的插件存储里，不会上传，并按上文加密保存。
- 重置后的旧地址保留在“历史地址”里，后续误打入的资金可点“恢复”继续转出；也可在会话页导出私钥。
- “历史地址”列表会显示每个旧地址的原生币余额（代币会话同时显示代币余额），余额不为零的会标出“有余额”；可点“刷新”重新查询。清空历史会永久删除这些地址的私钥，上面留存的剩余 gas 将无法取回。
- 链上转账是公开的：“交易所 → 中转地址 → B”这条路径任何人都能在区块浏览器上查到。
  本工具只是让交易所的提币记录里不直接出现 B，普通模式不能提供混币级别的匿名性；Tornado 模式也不保证无法关联，尤其是同一批次全部汇总转入 B 时。
- Gas 钱包的私钥和其他私钥一起加密保存；页面解锁期间它可被用来自动垫付，请只放少量 gas 费。
- Gas 钱包会在链上与每一个中转地址产生转账记录，因此通过它可以把你的各个中转地址关联起来。
- 第一次使用请先小额测试。
